# 白板多选、对齐与框选验收（2026-11-22）

按 diagram-guide 七层矩阵的第一层“基础绘图”补齐 Miro/Lucid/draw.io 的地板能力。

## 新增能力

- **Shift + 点击**：追加/移除多选；单选仍显示原属性面板。
- **框选**：选择工具在空白处拖动，按矩形范围选中图元；Shift 框选追加。
- **Ctrl/Cmd + A**：全选图元（不含连接线）。
- **组拖**：拖动任一已选图元，所有选中图元一起移动；松手后一次性写入 Yjs。
- **对齐**：左、水平居中、右、顶、垂直居中、底。
- **分布**：水平分布、垂直分布（至少 3 个图元）。
- **复制所选 / 删除所选**：多选状态下的批量操作。
- 多选时显示独立工具栏；单选属性面板隐藏，避免编辑冲突。

## 生产验收

在新建临时白板上执行：

| 检查 | 结果 |
| --- | --- |
| 新增 3 个矩形 | 3 个 |
| 单选时多选工具栏 | 不显示 |
| 第 2 个 Shift 点击后 | 显示“已选 3 个” |
| 顶对齐 | 三个矩形 top 均为 523 |
| 水平分布 | 两个间距均为 75 |
| 拖动其中一个已选矩形 | 三个矩形位移均为 [60, 40] |
| 框选前两个矩形 | 显示“已选 2 个” |
| 控制台错误 | 仅第三方 iframe 的 sandbox localStorage 警告 |

## 边界

- 连接线和自由箭头不参与对齐/分布/复制；绑定连接线会跟随两端图元移动。
- 组拖只移动图元，自由箭头不会跟着移动。
- 多选不对连接线做框选；连接线仍需单选后删除。
- 单白板 500 图元上限不变。
