## 修复内容

### 1. 图元与箭头

- 左侧工具按钮此前只有选中/平移/连接/更多图元有图标；矩形、椭圆、便签、文字、箭头、菱形、思维主题的 `ShapeGlyph` 对基础类型不渲染，按钮实际是空的。现改为 lucide 图标，工具全部可见。
- “箭头”工具从“点击生成一个独立箭头图形”改为“从一个图元拖到另一个图元生成绑定连接线”；空画布点击会提示从一个图元拖到另一个图元。
- 连接点增加透明大命中区（14px 视觉命中，随缩放收敛），拖动时目标图元显示虚线高亮。
- 连接落点改为读取 Y.Doc 的最新状态，而不是 React 渲染快照；刚新增的图元也能立即被连接。落点有 8–24 世界单位容差。
- 连接失败不再静默：拖到空白处会显示“没有找到目标图元”的提示；成功创建会清除旧错误。

### 2. AI 白板 Agent

- 计划协议从 `note/move/connect` 扩展为 `add/note/update/move/connect`，最多 20 个操作。
- 支持新增矩形、椭圆、菱形、便签、文字、思维主题；支持修改文字、移动、绑定连线。
- 新增图元可省略坐标，由客户端按 3 列网格自动布局；流程图提示要求横向 ≥220、纵向 ≥140。
- 前端预览显示“将执行 N 项变更”和逐项标签；应用时写入 `type/geometry/text/fill/binding/order`，不再只更新 geometry。
- 错误信息区分服务端 400/409/422/429/503 与模型返回；白板未同步时明确提示等待，而不是静默无响应。

### 3. 文档编辑

- 正文工具栏统一为圆角 token 样式，激活态使用 indigo 而非蓝色硬编码。
- 文档页头的“共享权限/历史版本/重命名”和侧栏“评论/历史/权限”改用统一按钮样式。

## 生产验收

| 场景 | 结果 |
| --- | --- |
| 新增矩形 + 椭圆 | 2 个图元 |
| 拖动选中图元连接点到目标 | 1 条绑定连接线 |
| “连接节点”两次点击 | 第 2 条连接线 |
| “箭头”工具从矩形拖到椭圆 | 第 3 条连接线；独立箭头图形 0 个 |

| 文档加粗 + 一级标题 | `bold=true`、`heading=true`、工具栏可见、无控制台错误 |

## 边界

- 连接线仍必须绑定两个图元，暂不支持自由起止点的独立箭头。
- AI 不支持删除图元、修改颜色/线型、生成任意图形库形状；单次最多 20 个操作。
- 白板仍有 500 图元上限；AI 选区最多 20 个图元。
- 生产探针在新建的临时白板/文档上执行，结束后已归档，不污染演示内容。
- 浏览器控制台唯一异常是第三方 iframe 的 sandbox localStorage 警告，与本次功能无关。
