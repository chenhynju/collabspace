# Diagram workspace delivery — 2026-10-21

Source: ce67e496546d034eae90fb28c89c0e0726cd2fd1. Product/design: docs/collaboration/DIAGRAMS.md. This release extends the existing collaboration engine; it does not replace document editing or introduce another identity/tenant model.

## Delivered behavior

Flowchart decision diamonds; node-bound labeled straight/elbow/curve connectors with rectangle/ellipse/diamond perimeter clipping; additive templates; optional grid snapping; double-click text editing; SVG export. Mind roots/children/siblings, Tab/Enter on canvas, deterministic explicit layout, Ctrl/Cmd-Z and Shift-Z, individual undo and offline branch merge. Mixed-board layout avoids existing non-mind shapes, templates use vacant vertical space, opening an existing board fits content once, and Fit All restores the complete viewport.

Bounded Mermaid source exchange: basic flowchart LR/TD/TB and indentation-based mindmap; parse-preview before additive CRDT write, no partial mutation on error, text/topology export, strict limits. No embedded renderer, arbitrary HTML or runnable directives. See the UI help and design for unsupported grammar and lossy layout/style interchange. This is not full draw.io/Visio/.drawio/.vsdx/Mermaid compatibility or obstacle-avoiding routing.
