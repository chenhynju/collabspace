冲突测试最初使用 DOM 全部文字断言，误把光标姓名装饰计入正文而失败（conflict-first-results.json）。最终测试排除 .collab-caret 装饰，只比较编辑器语义正文，并额外创建不可变版本、解码 Yjs 状态对比。它不会通过过滤实际正文来掩盖丢字。

双账号测试中，在线同位置插入 Alpha/Beta，离线分别追加 offline-A/offline-B；重连后每段出现一次、两端完全一致，刷新仍一致，命名版本内容一致。最终结果、顺序、SHA256 和重连耗时以 conflict-proof.json 为准；CRDT 不理解编辑意图，不承诺并发改写自动生成自然语言上正确的内容。

## Redis 的真实边界

API 实际连接 RedisIoAdapter，供原有 Socket.IO 房间广播；OAuth 使用 Redis 保存限时 state。原生文档服务当前单实例，presence 在进程内，正文事实源是 PostgreSQL。Redis 不是正文权威数据库，本轮不宣称完成文档多实例 Pub/Sub、容灾或水平扩展。Redis 健康检查 up 也不单独构成协作业务通过。
