# CollabSpace 用户手册

> 版本：2026-11-21 ｜ 生产站点：https://collabspace.purelamp.uk
> 面向使用者（第 1–8 章）与运维者（第 9 章）。演示账号由作者单独提供，不在仓库保存密码。

## 1. 这是什么

CollabSpace 是一个多租户协作空间：同一组织内建工作区、项目，在项目里写文档、改 Office、画白板、发消息，并在权限与审计约束下使用 AI 和语音。

三层结构：

```text
组织（Organization）→ 工作区（Workspace）→ 项目（Project）→ 文档 / 白板 / Office 文件
```

一个账号可以属于多个组织，用顶栏组织切换器切换。所有内容挂在项目下；能不能看、能不能改，由组织成员身份 + 项目访问 + 内容 ACL 共同决定。

## 2. 快速开始

1. 打开生产站点，注册账号并完成邮箱验证。
2. 首次登录后创建组织、工作区和项目。
3. 在「设置 → 成员 / 邀请」邀请同事，分配角色。
4. 进入「协作空间」创建文档、白板或上传 Office 文件。
5. 用「共享权限」把内容授权给项目成员或客户（Commenter/Viewer）。

本地开发账号与启动方式见第 9.6 节；生产演示账号请向作者索取。

## 3. 角色与权限

| 角色 | 能做什么 |
| --- | --- |
| OWNER | 全部组织设置、成员、角色、审计、监控；全部项目内容 |
| ADMIN | 按菜单授权管理成员、角色、部门、邀请、审计 |
| EDITOR | 编辑正文、评论、创建版本；不能改 ACL |
| COMMENTER | 只读正文 + 评论 |
| VIEWER | 只读 |

要点：

- 项目可见不等于文档可见；文档/白板/Office 有独立授权列表。
- 最后一个有效 Owner 不能被移除或降级。
- 撤销权限后，已建立的编辑会话会被冻结；本地未保存草稿只能导出，不能上传。
- 组织管理员不天然能读正文，需要显式内容授权。

## 4. 界面导航

- **顶栏**：菜单（打开抽屉）、组织切换、概览、项目空间、协作空间、消息、全局搜索（`Ctrl/Cmd+K`）、AI 助理（`Ctrl/Cmd+J`）、通知、个人菜单。
- **左侧抽屉**：完整导航、搜索、新建项目/工作区、工作区与项目快捷入口、设置入口。
- **右侧 AI 助理**：对话式操作；写操作先出计划，确认后执行。
- **沉浸式编辑页**：文档和 Office 编辑页隐藏顶栏，用页面内浮动按钮打开导航或 AI。
- **设置**：`/settings`，集中主题、个人资料、语音与数字分身、成员、权限、审计、系统与监控。

## 5. 核心流程

### 5.1 建项目与邀请成员

1. 「项目空间」→ 新建工作区 / 新建项目。
2. 项目详情页管理成员、状态和协作内容。
3. 「设置 → 邀请」输入邮箱、选角色；邀请 7 天有效，受邀邮箱锁定。
4. 成员接受后出现在「设置 → 成员」，可调整角色或停用。

### 5.2 创建内容

「协作空间」或项目详情页提供五个类型：文档（富文本）、Markdown、白板/Mermaid、Word、Excel、PowerPoint。

- 在「全部内容」视角点卡片 → 选择存放项目 → 直接创建并打开。
- 在项目视角点卡片 → 直接创建。
- 「上传文件」支持 `.md/.mmd/.docx/.xlsx/.pptx` 等；普通文件 ≤20MB，源码类 ≤200KB。

### 5.3 文档协作、评论与版本

- **实时编辑**：多人同时改正文，右侧显示在线成员；断线后本地草稿保留，恢复网络自动补传。
- **保存状态**：只有收到服务端持久化确认才显示“已保存到服务器”；本地待传会单独提示。
- **评论**：选中正文 → 写评论；支持回复、解决/重开；原文删除后仍可在未定位列表找到。
- **版本**：
  - 自动快照：有编辑时每分钟至多一份，侧栏时间轴可浏览。
  - 命名版本：手动打检查点（如“客户确认 v1”）。
  - 预览只读；恢复会创建**仅自己可见的新副本**，不覆盖当前文档。
- **共享权限**：逐人授权/降级/撤销；撤销后旧会话冻结。

### 5.4 白板与 Mermaid

- **Mermaid**：图形 / 源码 / 分屏三视图，源码为权威；支持流程图和思维导图。
- **自由画布**：左侧工具栏选择矩形、椭圆、便签、文字、箭头、菱形或思维主题；点击画布放置，拖拽移动，双击或属性面板改字。
- **箭头 / 连线**：选择“箭头 / 连线”后，从一个图元内部拖到另一个图元生成绑定连接线；从空白处拖动生成自由箭头。也可以用“连接节点”依次点击两个图元。
- **连接点**：选中图元后拖动边缘蓝色圆点连线；拖动时目标图元会虚线高亮，松开即连接。
- **多选与框选**：Shift+点击追加/移除图元；选择工具在空白处拖动框选；Ctrl/Cmd+A 全选图元。
- **对齐与分布**：多选后顶部出现工具栏，可左/中/右、顶/中/底对齐，水平或垂直分布，批量复制/删除。
- **组拖**：拖动任一已选图元，选中的图元一起移动；连接线跟随两端图元，自由箭头不跟随。
- **模板**：流程图/思维导图模板；业务图表模板库覆盖流程、架构、审批等高频场景。
- **导入/导出**：导入 `.mmd` 为追加；导出 SVG/PNG 或 Mermaid 源码。
- **AI 改图**：选中图元或区域 → 描述目标 → 预览“将执行 N 项变更” → 确认后单次提交；支持新增图元、改字、移动和连线，撤销只回退本次操作。
- 单白板最多 500 个图元；AI 单次最多 20 个操作；自由箭头不绑定图元，AI 连线仍只支持绑定。

### 5.5 Office 文件

- 上传后在文件库点「打开」进入在线编辑器。
- 「服务器版本 vN」显示保存状态；「保存到服务器」打检查点。
- 文件操作：重命名、另存私有副本、导出 PDF。
- 图片上传慢时可先用「先缩小图片」本地压缩。
- 权限变更会冻结会话，防止旧会话覆盖他人成果；可从恢复候选找回未保存内容。

### 5.6 消息与语音

- **消息**：单聊/群聊、已读回执、输入中、图片和文件消息。
- **语音听写**：点输入框麦克风 → 录音 → 停止后服务端识别 → 转写回填为可编辑草稿 → 检查后发送。
- 单次录音 60 秒、转写 4000 字；失败不会自动重试，也不会把失败伪装成成功。
- **朗读**：消息时间旁的悬浮按钮使用浏览器系统朗读；不是服务端 TTS。

### 5.7 AI 助手与工作助理

- **协作助手**：摘要、行动项、翻译、写邮件；邮件必须预览确认后才发送。
- **AI 工作助理**：用自然语言查项目、成员、任务、文件；写操作只返回计划，点“确认执行”才落库。
- **AI 改文档/Office/白板**：先选范围 → 生成预览 → 确认应用；目标版本变化或权限撤销时进入冲突/失效。
- **AI 生成白板流程图**：不选中图元时，可直接描述“创建开始、处理、验收、交付并连接”，AI 会新增图元并按网格自动布局；生成后先预览，确认才写入。
- 未配置模型密钥时保留规则能力和文本操作，不显示假的模型结果。

### 5.8 全局搜索

`Ctrl/Cmd+K` 打开；输入关键词搜索页面、项目、文档、消息等。结果受组织与资源权限过滤，不会跨组织泄露。

### 5.9 设置

- **主题**：编辑风 / 经典浅色，立即生效并记住选择。
- **个人资料**：修改组织内显示的姓名（1–50 字符）；邮箱只读。
- **语音与数字分身**：查看服务商、云区域、ASR/TTS 状态、60s/4000 字上限；管理私有照片/视频草稿。
- **账号与安全**：修改密码、查看登录状态。

### 5.10 管理后台

「设置」内按权限显示：

- 组织：成员、邀请、部门与岗位、角色权限。
- 治理：审计日志、通知公告。
- 系统：菜单、字典、参数、登录日志。
- 监控：在线用户、服务监控、缓存、定时任务、数据库会话。
- 套餐与订阅为沙盒，生产不展示收款入口。

## 6. 账号与安全

- 注册需邮箱验证；没收到请检查垃圾箱并重发。
- 登录失败限流：同一 IP+邮箱 5 分钟内错 5 次，第 6 次起 429，窗口过后自动恢复。
- 改密后旧登录态失效；忘记密码走登录页“重置密码”。
- 退出登录会清理本机离线草稿缓存；换账号前如有未同步内容，请先联网同步。

## 7. 已知边界

| 能力 | 状态 |
| --- | --- |
| 文档/白板/Markdown/Office 协作、版本、权限 | 生产已验收 |
| ElevenLabs ASR/TTS | 生产已配置，录音结束后识别/合成 |
| 私有素材草稿 | 可用；仅本人可见、7 天过期、不外发、不训练 |
| 真人数字人视频 | 未接供应商，不能生成 |
| 支付（Stripe/PayPal） | 仅沙盒，收款入口隐藏 |
| 会议/音视频 | 生产关闭（`MEETINGS_ENABLED=false`） |
| 跨实例正文同步、跨地域 | 未验证；当前单实例 |
| 容量 | 单文档 5MiB；WS 单帧 256KiB；白板 500 图元 |
| 白板 AI | 单次最多 20 个操作；不支持删除、改颜色/线型；AI 连线只支持绑定图元 |

## 8. 常见问题

**Q：为什么保存状态一直显示“本地待传”？**
A：检查网络和协作服务是否可达；只有收到服务端 ACK 才算云端保存。不要直接关页面，先导出草稿。

**Q：为什么同事看不到我分享的文档？**
A：项目可见不等于文档可见。打开文档「共享权限」确认对方已获授权，且账号/组织状态有效。

**Q：为什么撤销权限后对方还能看到旧内容？**
A：已经下载到本地的内容无法远程“收回”，系统会阻止继续上传和新内容读取。敏感资料请及时轮换。

**Q：为什么语音按钮识别失败？**
A：确认麦克风权限、录音时长 ≤60 秒、网络可达；供应商失败不会自动重试。可改用键盘输入。

**Q：为什么真人数字人不能生成？**
A：真人视频供应商尚未接入；页面只允许保存私有素材草稿，不会显示虚假成功或可播放结果。

**Q：为什么会议入口不见了？**
A：生产环境关闭了会议开关；代码保留，但不把设计当成已上线。

## 9. 运维附录

### 9.1 生产架构

```text
浏览器 → Vercel（前端）→ 腾讯云 Docker Compose
  ├─ collabspace-api（NestJS API）
  ├─ collab WebSocket 服务（/collab）
  ├─ PostgreSQL 16（FORCE RLS）
  ├─ Redis（IM 广播/缓存，可选降级）
  └─ ONLYOFFICE 引擎（Office 编辑）
```

### 9.2 健康检查

```bash
curl https://collabspace-api.purelamp.uk/api/v1/health/ready
```

期望 `status: ok`，`database` 与 `redis` 为 `up`。登录后在「设置 → 监控」查看服务、缓存、在线用户和数据库会话。

### 9.3 发布与回滚

- 前端：Vercel 生产部署，确认 Ready 并别名到 `collabspace.purelamp.uk`。
- API：打包 → 上传 → 镜像构建 → 健康等待 → 线上验收 → evidence → 提交/标签。
- 回滚：保留 previous 镜像；数据库只做 additive 迁移；回滚不 DROP 表。
- 详细命令与最近发布记录见 `evidence/collaboration/RELEASE-AUTH-HARDENING-2026-11-12.md` 与 `REVIEW-RELEASE-2026-10-30.md`。

### 9.4 备份与日志

- 发布脚本执行 `pg_dump` + uploads 打包并校验 sha256；**正式还原演练尚未做**。
- 日志：`docker logs --since 10m collabspace-api-1`。
- 合成测试邮箱（`@example.invalid`）的邮件以 `[verify] / [invite] / [reset]` 前缀落日志。

### 9.5 环境变量

生产密钥只放服务器 env 与 Vercel 环境变量，不进入仓库。语音相关：

```text
SPEECH_PROVIDER=elevenlabs
ELEVENLABS_API_KEY=...
ELEVENLABS_VOICE_ID_ZH=...
ELEVENLABS_VOICE_ID_EN=...
ELEVENLABS_STT_MODEL=scribe_v2
ELEVENLABS_TTS_MODEL=eleven_multilingual_v2
```

完整清单见 [第三方服务](THIRD-PARTY-SERVICES.md) 与 [语音供应商选型](SPEECH-PROVIDER-SELECTION.md)。

### 9.6 本地开发

```powershell
pnpm install --frozen-lockfile
pnpm local:up
```

默认 Web `43120`、API `43121`、协作 WS `43122`。本地合成账号 `owner@acme.dev` / `admin@acme.dev` / `member@acme.dev`，密码在 `.test-runs/collab-local/config.json`（仅本地，勿用于生产）。

测试：

```text
pnpm --filter @teamspace/api test
pnpm --filter @teamspace/web test
pnpm test:collab
node node_modules/@playwright/test/cli.js test
```

### 9.7 演示路线（给面试官）

1. 打开概览，说明组织/工作区/项目三层结构。
2. 进入项目文档，两个浏览器同段编辑，展示在线成员与实时合并。
3. 一个浏览器断网续写，恢复后展示本地待传 → 已保存到服务器。
4. 选中段落评论，另一账号解决；创建命名版本并只读预览。
5. 打开白板，拖图元/连线，切 Mermaid 源码/分屏，导出 SVG。
6. 打开 AI 助理，生成一个写操作计划，确认执行，再重复提交证明只生效一次。
7. 打开设置 → 语音与数字分身，展示 ElevenLabs 已配置、语音输入与素材草稿边界。
8. 打开审计日志，展示 actor、资源、前后差异与 trace_id。
