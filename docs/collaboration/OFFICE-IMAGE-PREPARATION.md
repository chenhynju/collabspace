# Office 图片上传前优化

2026-10-25 用户授权继续优化PPT图片上传、加载速度。图片发送字节量是已测瓶颈之一；本轮提供用户可选的本地图片副本，保留原生编辑器的插入、授权与保存链路。未修改Office品牌、引擎或代理部署。

| 追溯 | 契约与验收 |
| --- | --- |
| P-IMG01 / BR-IMG01 / D-IMG01 / AT-IMG01 | 可编辑的已连接Office页面展示“图片上传慢？先缩小图片”。选图→质量档位→本地预览→下载→原生插图。选择/预览不上传，不表示已经插入或保存。 |
| P-IMG02 / BR-IMG02 / D-IMG02 / AT-IMG02 | 原图档返回同一文件；均衡最长1920像素、质量0.86；更小最长1280像素、质量0.75。保持比例，不放大，WebP保留透明度；无法生成更小WebP时保持原图。展示实际前后KB，用户检查文字/图形清晰度后决定。 |
| P-IMG03 / BR-IMG03 / D-IMG03 / AT-IMG03 | 优化仅接受PNG/JPEG/WebP，输入20MB、解码后3200万像素上限。浏览器解码不属于进程级内存隔离；不支持格式/解码失败可选原图。动画图不做优化。原图档不经过解码。 |
| P-IMG04 / BR-IMG04 / D-IMG04 / AT-IMG04 | 换图片、换质量、切组织/文档或卸载后旧处理结果不回写，释放预览URL；不调用模型或第三方压缩服务。 |
| P-IMG05 / BR-IMG05 / D-IMG05 / AT-IMG05 | 合成原图/副本交替实测，媒体响应须对应本次upload返回URL，不能拿第一张后台图片代替。记录POST与媒体完成分别耗时；关闭会话后下载PPT核对媒体尺寸并重开。 |

这是可选的有损副本，适合普通屏幕演示照片。高分辨率打印、截图小字、品牌素材应选原图。浏览器编码可能移除元数据或改变色彩，不承诺无损、所有浏览器输出一致或固定时间收益；请求等待时间还需线路/代理/引擎的逐请求证据。

验证：`pnpm exec playwright test tests/browser/office-image-preparation.spec.cjs --reporter=list`（真实浏览器编码、透明度、尺寸、组件预览/下载/原图选择），`pnpm --filter @teamspace/web exec tsc --noEmit`，`pnpm --filter @teamspace/web run build`。线上合成诊断见性能证据，不把本地功能构建视为已发布。
