# 可操作区域与占位内容

2026-10-25用户要求：功能区域按钮化，不提供实际功能的元素移除。本轮覆盖IM、语音/形象、协作助手及共享文件选择控件；不替换Office引擎内部工具栏。

## P-AUI / BR-AUI

- 展开、播放、录音、任务取消、文件选择等操作使用明确按钮；静态名称、状态和必要的权限/隐私说明仍作为文字。
- 没有供应商配置的听写、云朗读和真人风格入口不显示。语音选项保留简短的未配置说明，不静默使用其他供应商。
- 移除“Agent形象尚未启用”和大面积空结果卡；停止/取消按钮仅在存在相应操作时出现。资料不足、任务处理中等暂时禁用状态继续保留，避免布局不明和重复操作。

## D-AUI

- Disclosure复用Button，原生键盘Enter/Space、aria-expanded/aria-controls明确对应内容。形象与逐消息语音关闭时卸载；主语音工具保持状态，避免收起导致录音遗失。
- FilePicker以真实按钮打开原生文件选择器，保留原生input、拖放、文件名和大小校验；沿用共享业务回调。
- 云功能仅改变前端展示，服务端鉴权、组织/RLS、供应商未配置拒绝仍为权威。未配置不显示听写，不把可见性作为安全边界。
- 仅提供实际可预览的3D卡通；隐藏真人选项不删除已有服务端外观偏好。保存默认语言仍保留原style；未来真人功能需独立验收后再恢复入口。
- Agent状态仍由运行时返回；停止播报只在正在系统朗读时提供，取消业务任务仅在运行中提供。

## AT-AUI

1. IM按钮可键盘展开、收起，关闭3D预览卸载画布；未配置操作/占位文字不存在。
2. 文件选择按钮实际打开系统选择器，超大VRM保持本地并报错；原录音取消/丢弃释放轨道且不外发。
3. 助手空闲无取消/停止按钮；显式运行时替身验证运行中取消、完成后编辑结果和展开收据，不调用模型或邮件服务。
4. 原听写五项、原音双账号鉴权、邮件确认预览和语音旧结果失效继续回归。真实Azure/真人服务未配置，仍不计真实效果验收。

命令、失败修复、发布身份、线上成绩见[本轮验收](../../evidence/collaboration/ACTION-UI-2026-10-25.md)。
