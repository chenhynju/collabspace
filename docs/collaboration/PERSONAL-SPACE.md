# 可选组织名称与个人协作空间

组织名称是展示信息，不是功能开关。空名称注册沿用后端自动创建组织、ACTIVE成员关系和OWNER授权；个人空间与团队空间使用同一套认证、租户上下文、RBAC、资源ACL与RLS。不得把未填公司作为功能拒绝条件，也不得让新用户自动加入公共组织或获得其他组织/平台超级管理员权限。

本次修复前端组织缓存：每次获得登录令牌时撤销旧客户端会话、清空旧用户/组织/权限/IM；loadProfile只接受当前令牌对应的响应，并从服务端有效组织成员关系选择缓存所属组织或第一个可用空间；旧组织缓存不属于新账号时自动修复。组织权限响应同时校验令牌和组织，避免账号切换后晚返回污染。后端成员校验保持权威，不放宽NOT_MEMBER。

注册页说明留空自动建立独立空间，空白字符串在前端标准化为未填写，品牌改为CollabSpace。邮箱验证保留；不把绕过邮箱验证当成修复。现有注册FREE资源配额对填/不填名称一致，本轮不新增收费门槛，不改真实支付/套餐配置。平台运维权限不属于普通个人空间默认授权。

新增回归覆盖旧账号缓存、新注册有效OWNER成员关系、刷新修复无效组织、暂停成员不被选中及跨账号晚响应。真实浏览器采用合成新账号、不填名称完成注册及既有console验证链接流程；验证普通工作区/项目/图表保存与两个组织的HTTP/WS票据拒绝。console路径仅测试既有模拟邮件提供器，不宣称真实邮件投递验收。
