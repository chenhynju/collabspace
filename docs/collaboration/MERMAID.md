## 内容与协作契约

- BOARD 的 Y.Doc 新增 `mermaid: Y.Text` 根，沿用既有 `shapes`。服务端仅接受这两个根，源码最多 32000 个 UTF-16 字符，只允许纯文本 delta，无富文本属性或嵌入对象。数据库表、组织与 ACL 不另建一套。
- 源码按最小连续文本差量写入 Y.Text，复用 IndexedDB pending、鉴权重连、持久化后 ACK、撤权和版本服务。并发字符依 CRDT 收敛，不承诺自动合并作者语义；语法错误属于可保存草稿，预览显示诊断，不能用旧图伪装当前内容。
- UndoManager 只追踪本机源码操作。输入法组合期间遇到远端编辑，保留本机组合草稿供手动合并，不直接用旧全文覆盖远端内容。此交互需单独浏览器验收，未测不得宣称通过。
- `.mmd` 下载保留完整源码；历史预览用同一渲染器，恢复为新的私有副本时复制源码到新的 Yjs lineage。图表源码参与现有版本和权限边界。

## 图形编辑边界与旧白板

已有自由画布及其图元不自动转换或覆盖。旧白板有 shapes 时保留原入口，用户可切换到 Mermaid 工作区；两份内容明确独立保存，不做隐式双写。自由画布仍支持拖放、节点移动/大小/文字、连接线与思维导图。

Mermaid 工作区的图形由源码执行，已支持流程图拖入节点/拖动连线与基础思维导图子树拖动，这些操作修改源码；其他类型通过源码修改。任意 Mermaid 语法与自由几何画布没有通用无损双向转换，不能把当前基础 flowchart/mindmap 导入器称为完整转换。进一步图形编辑以受支持图表的 AST/源码定位补丁扩展；布局坐标作为视图元数据，不冒充 Mermaid 标准语法。不支持的编辑保留源码并提示，不重新生成简化源码覆盖用户内容。

## 渲染和安全

客户端动态加载官方渲染器；flowchart（含 subgraph）、mindmap、sequenceDiagram、classDiagram、stateDiagram-v2、erDiagram 为本次明确验收样本。其他官方语法不逐一宣称已验证。源码保留原样，官方 parse/render 负责诊断和显示，不使用有损转换后的 shapes 作为图形事实源。

应用固定 strict 模式、禁用 HTML labels，限制 maxTextSize=32000/maxEdges=500。禁用源码配置指令、frontmatter、外部 URL/HTML，避免图表修改安全配置或发起外部资源请求。生成的 SVG 放在无任何授权的 sandbox iframe 中；CSP 禁用脚本、网络、表单和 base URI，不执行 Mermaid bindFunctions。配置拒绝影响预览，不删除源码草稿。仍须持续维护官方依赖安全更新；此设计不等于无限容量或任意图表性能证明。

## 后续 AI Agent 接口契约

源码是未来 Agent 读取、生成和修改的统一载体。后续受控入口应接受 documentId、租户上下文、基准版本/状态向量及文本补丁，先检查服务端权限、基准是否过期，生成差异预览并验证语法，再提交到既有 Yjs 写入/审计路径。不能通过新的 REST 全量写入绕过持久化 ACK、ACL 和并发协作，也不能自动把远端新内容覆盖掉。本次不接入 AI 服务或自动授权 Agent 写生产内容。

- MM01：新白板默认 Mermaid，六类图表的源码/图形/分屏、模板及 `.mmd` 下载。

- MM03：语法错误可保存和刷新，显示诊断；配置/外部资源预览拒绝；不影响其他文档。
- MM04：真实非特权 PostgreSQL 持久化、大小/嵌入拒绝、版本恢复副本/私有 ACL、原有文档及自由画布回归。
- MM05：第二轮受支持拖拽见 I201；任意语法的图形回写与 AI 受控修改仍属后续，不将图形展示说成全语法可拖动编辑。
