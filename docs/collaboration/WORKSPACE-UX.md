# 统一协作空间 UI/UX — 2026-10-25

## P-UX / BR-UX

用户要求整理散乱布局、合并协作空间与协作助手，美化原生 Choose file 控件。边界清楚的功能使用图标和名称直接展示，减少进入下拉列表的点击。

## D-UX

- Figma 可编辑设计：[统一协作空间](https://www.figma.com/design/bC8YHgedUX0LiMhjdScn77)，桌面文件页 `4:130`、助手双栏 `4:327`、移动端 `4:434`。使用已有 Tailwind 的 slate/indigo 颜色与系统字体；设计中文使用 Noto Sans SC 对应可用中文无衬线字体。图标与代码来自现有 lucide-react，不引入远程图片运行依赖。
- 侧栏统一为协作空间。文件协作与 AI 助手直接切换；旧 `/assistant` 地址继续打开统一空间的助手视图。六种创作入口保持可见，新建对话框也用图标选择类型。
- AI 五个直接入口：生成摘要、提取行动项、中译英、英译中、写邮件。文件视图提供快捷入口，助手视图显示当前功能及说明。仅选择功能不调用模型。
- 输入与结果在宽屏双栏显示，小屏纵向排列。项目上下文沿用现有访问授权；切换组织重挂载并取消旧请求。切换文件/助手视图保留输入，离开助手时停止朗读及未完成生成。
- 通用 FilePicker 保留可访问的原生文件输入与系统选择器，视觉展示图标、拖放区域、所选文件名和约束说明。用于工作区上传、助手资料与 Office 图片准备。原有大小、解析、授权及保存验证仍由原业务路径执行。
- 摘要、翻译、邮件均沿用原接口及额度、缓存、限长。邮件必须预览再确认；保留同编号重试、会话恢复和“受理不等于送达”提示。测试不真实发信，不调用付费模型。

## AT-UX

1. 文件视图一次点击进入指定 AI 功能，五项功能无下拉菜单；新建类型直接选择。
2. 项目上下文传递；切换文件/助手后正文保留；组织切换清除旧上下文。
3. 上传控件能选择文件并展示文件名，拖放走相同业务校验；禁用状态不能绕过。
4. 摘要、双向翻译限长、朗读生命周期、邮件预览/超时/同编号恢复回归。
5. 390px 无全页横向溢出，桌面双栏、移动导航可用。类型检查、生产构建与浏览器记录见本轮 evidence。

范围：优化协作入口和助手工作流；Office 引擎内的原生品牌及工具栏未改变。
