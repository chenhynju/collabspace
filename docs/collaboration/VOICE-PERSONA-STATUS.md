- 继续融入现有系统：NestJS/TypeScript API、Next.js/React/Tailwind UI、Prisma与原生SQL、PostgreSQL组织+actor RLS、现有鉴权/审计和私有FILE附件。没有独立部署第二套业务系统。

- 浏览器MediaRecorder/Web Audio转PCM；Azure REST为已实现的语音适配器；Three.js 0.180.0、three-vrm 3.5.5；BullMQ 5.61.0为关闭的可选队列。真人供应商未锁定，不引入新常驻服务或付费资源。

## 待完成顺序和验收标准

1. **真实语音服务配置和小样本验收（BLOCKED）**：补齐Azure地区/密钥；中文、英文、混说、噪声、空音频、失败/取消样本；检查文字修订后发送、TTS真实可听、网络和账单。先定义可接受质量与预算，再记录真实成绩。凭据不得进入源码。
2. **生产数据保留与费用门禁（待实现）**：无人访问时定时清理、备份保留策略、货币金额硬上限、实际费用核对。禁用云服务期间不能用无调用数据宣称这些通过。
3. **真人供应商与授权资产（BLOCKED）**：确定异步/实时需求和一家供应商，验证本人/组织授权、音频版本绑定、私有视频鉴权、失败降级及邮件外部分享边界。
4. **Agent/Skill持久运行时（待实现）**：已有真实受限工作流及身份/runId/结果引用；后续补持久化、恢复、调度及通用Skill权限边界。真实云播报联动仍受Azure配置阻塞，不能将停止播报等同取消业务任务。
5. **形象资产和兼容性（待验收）**：有效VRM与坏文件恢复、精确嘴型需求、移动端与Safari/Firefox、长时间预览资源释放；不以画布出现替代模型授权和音频同步。
6. **后台队列与容量（开启前门禁）**：Redis故障、重复投递、多进程竞争、worker崩溃恢复、持久队列与压测；完成后再考虑生产启用和服务器迁移。

真实邮件外发、付费资源开通、生产发布/迁移仍按已授权范围执行。本轮不为补测试而真实发信，不把替身的识别/播报记成真实供应商成绩。
