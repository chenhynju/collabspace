# Mermaid 图形编辑与定位

2026-10-26，用户要求实际画布拖入图元、按位置移动、部分删除。对应P/BR/D/AT-MPOS，覆盖此前仅侧栏关系拖拽和自动布局的行为。发布成绩见[验收报告](../../evidence/collaboration/MERMAID-POSITION-2026-10-25.md)。

## BR-MPOS / D-MPOS

- 流程图在实际画布接受图元拖入；坐标按当前缩放换算，移动节点后共享、刷新和重新打开保持。侧栏用于图元库、节点属性和明确点选连线。
- 单选、Shift多选、Delete/Backspace与删除按钮只移除选中节点及关联的受支持边，其余定义和边保留。复杂批量/引用语法安全拒绝，源码不变。
- `%% collab-position ID x y`为本应用位置注释，不冒充Mermaid标准布局语法；外部渲染器忽略注释并自动布局。本应用导出SVG/PNG使用当前定位后的官方SVG，.mmd保留原源码和注释。
- 恢复自动布局仅清理本应用位置注释。沿用Y.Text最小差量、UndoManager、持久化ACK、组织/文档ACL、离线和版本；没有数据库迁移或并行状态权威。
- 无授权sandbox/CSP保持；父页只对官方SVG做惰性XML解析并在外层提供原生交互按钮，不在父页挂载SVG、不执行bindFunctions或放开iframe权限。
- 常见流程矩形/菱形及新增标准图元可定位。普通有向边跟随，反向边分开走弧线并移动标签。自环、同向平行边、subgraph分组和自定义边ID暂时拒绝自由定位，错误明确且不改源码；已有此类源码继续用官方渲染和源码编辑。基础思维导图仍支持子树关系编辑；其他Mermaid类型不宣称自由几何编辑。

## AT-MPOS

1. 空画布和已有流程图拖入；50%缩放换算、移动、恢复自动布局、撤销/重做。
2. 双编辑同步、刷新保持、Viewer按钮与服务端权限、源码/历史边界。
3. 模板中间节点删除保留两侧和剩余边、多选删除、复杂引用拒绝。
4. 连线箭头/路径/标签跟随；反向边不重叠；不支持结构不改变源图。
5. 原图形/源码/分屏、24模板、导入、SVG/PNG导出与语法错误/安全拒绝回归。

真实运行结果按报告分列，不把本地测试或候选构建当成正式发布。
