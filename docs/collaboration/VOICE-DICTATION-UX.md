# IM语音输入体验

2026-10-25，用户要求以ChatGPT网页版听写体验为参考改进当前IM。对应P/BR/D/AT-VP02、03、07、08，供应商采用Azure海内外统一方案。

ChatGPT官方区分“把录音变成可编辑输入”的听写与持续语音对话。我们借鉴的是先录音、转写、编辑、发送的交互原则，不声称复用其内部实现。录音条、确认操作和菜单布局为本项目设计。[官方语音说明](https://learn.chatgpt.com/docs/features/voice)

## 主流程

1. 默认输入框仅显示文字草稿、附件/图片、语音输入和发送；正文自适应高度，Enter发送、Shift+Enter换行，输入法合成中的Enter不发消息。
2. 点击语音输入检查可用能力。未配置Azure则解释原因，不伪造识别、不录制后假装可转写；原音仍可在语音选项录制发送。
3. 麦克风授权中可取消；录音条显示计时和真实音量采样，可取消或确认。上限59秒停止以满足60秒服务端限制，进入保留录音/待确认状态；未确认不上传转写，不自动发消息。
4. 确认才提交PCM转写，显示处理中，可取消。中文/英文显式选择，默认读取个人偏好。
5. 转写成功追加到已有草稿并回到输入框，录音临时预览清除；用户编辑后手动发送文本。
6. 失败保留原草稿及本地录音供下载；UNKNOWN不盲重试，先核查或结束原请求，再明确创建新的任务。取消不保证供应商尚未计费。

## 次级操作

“语音选项”中保留原音试听/附文字发送、系统/云朗读、语言和历史任务核查；与听写共享同一权限和任务后端。主听写与旧工具互斥录制，原音发送不是听写默认行为。停止播报不取消Agent业务运行。

## 验收

- 新浏览器脚本tests/browser/im-dictation.spec.cjs：默认紧凑布局/配置不可用、实际录音到PCM替身转写、原草稿保留/人工编辑/手动发送、真实音量采样入口、取消释放轨道、UNKNOWN保留录音且不重复提交。
- 既有原音和TTS测试通过打开语音选项继续执行，不能删除原功能断言来适配新布局。
- Azure全球/中国云URL及失败关闭单测；真实识别质量仍因未开通而BLOCKED，不能把浏览器替身标为Azure验收。
- Agent新增工作流为只读项目事实+现有DeepSeek生成，进程内15分钟保留；无持久调度/自主工具规划，不宣称完整Agent引擎。
