# 在线图文写作（知乎式回答编辑体验）

2026-10-21 用户追加：在线文档应能直接编写图文内容。沿用现有 Tiptap 2.27.1 / Yjs，不另建编辑器或替换协作协议；参考成熟图文写作的交互，不复制知乎品牌和像素布局。

## 产品与内容

- 正文、一级至三级标题、粗体/斜体/删除线、项目列表/编号列表/任务、引用、行内代码/代码块、分隔线、链接设置/移除、清除格式、个人撤销/重做。工具栏显示当前格式状态、只读禁用，显示正文字数。
- PNG / JPEG / WebP 文件选择、剪贴板图片文件、拖入图片文件；单次最多5张、单张5MB。客户端解码检查并拒绝超过4000万像素的图；服务端独立检查大小和文件签名，SVG/HTML/其他格式拒绝。
- 正文 `documentImage` 原子块保存 `assetId / alt / caption / width(50|75|100)`，可选中、调整宽度、编辑说明、删除或拖动排序。说明是原子属性，多人改同一说明按 Yjs 属性顺序收敛，不保证语义合并。图片和文字混排、刷新保留、共享编辑；不把图片 base64 塞入每个 WS 更新。
- 异步上传期间继续打字，插入点用 Yjs RelativePosition 跟踪；插入位置删除或权限失效时明确报错。离线仍可编辑已有正文及图片引用；首次图片上传需要联网，已缓存正文并不等于图片离线缓存。上传失败不插入假图片。
- 不直接渲染外链 `<img>` / SVG / 任意 HTML。粘贴网页富文本时保留受支持文字格式，外链图片提示需要上传实际文件。

## 存储、权限和版本

新增 `collab_image`，图片字节、MIME、组织、文档、UUID、上传人、时间随独立 PostgreSQL 一起备份；小规模首版使用 bytea，避免额外对象存储和公开 URL。每文档累计20张或20MB，上传时锁定文档行检查额度。未引用/删除的图片暂时保留以支持历史版本，额度也计算这些图片；不提供未经版本引用分析的自动清理，不宣称无限媒体容量。

POST `/documents/:id/images` multipart 需要文档写权限；GET `/documents/:id/images/:imageId` 每次检查文档、项目、有效成员及租户权限，以 no-store / nosniff 返回字节，客户端用短期 Blob URL 展示并在销毁时撤销。没有公开分享 URL 或 URL token。已下载图像不能被远端“收回”，与离线正文边界一致。

服务端每次正文写入/批量更新检查图片属性、引用数量和 assetId 归属，防止把其他文档的图片 ID 塞入正文绕过 ACL。新增表强制 RLS，runtime 非 owner、无 BYPASSRLS；Prisma 映射保留 schema 工具兼容，但检查约束/强制 RLS 由显式 SQL 安装。

版本快照含完整图片引用，图片字节不可变保留。恢复副本事务复制该版本引用的图像记录到新文档（相同 image UUID、新 documentId），图片由新文档 ACL 独立控制，不依赖原文档后续授权。缺少原图时整个恢复返回 IMAGE_MISSING 并回滚，不创建假成功的残缺副本。

## 发布与验收

先备份，在现有独立数据库执行兼容新增表/约束/强制 RLS，授予既有 runtime 角色该表权限；再发布后端，再发布含新节点 schema 的前端。禁止 db push 到线上。文档 WS 鉴权要求 `docSchema:2`，服务端在任何正文同步前拒绝缺少新 schema 声明的 DOCUMENT 连接（CLIENT_UPGRADE_REQUIRED），避免旧 ProseMirror 把未知图片节点规范化删除。BOARD 仍接受旧版鉴权帧。此字段是防误用的版本协商，不能证明客户端实现；角色权限仍由服务端独立验证。已打开旧页面应刷新；后端先发期间旧文档连接可能暂不可用。出现新图片节点后不要回退不支持该节点的旧 UI/WS。回滚优先保留兼容节点、协议和表，禁止删除媒体数据。

RT01：两编辑者和只读者，标题/格式、文字与图片混排、说明/宽度同步，刷新和持久化。

RT02：文件选择、真实浏览器事件的剪贴板/拖入文件；非法类型、过大图片和无权限拒绝；不把模拟 DOM 事件说成真实操作系统剪贴板硬件测试。

RT03：非特权 PG/HTTP/WS 拒绝跨租户、伪造图片引用；Viewer 禁止上传；撤权后新的读取/写入拒绝。

RT04：历史只读预览显示原配图，恢复为私有新副本仍有配图，并可独立授权；缺图恢复失败且副本事务回滚。

RT05：原多人正文、评论、离线/ACK、IM、Mermaid 和自由画布回归。PASSED/BLOCKED/NOT_RUN 与部署源版本以对应 evidence 报告为准。未包含表格、视频、公式、裁剪、公开文章发布或 AI 写作。

官方节点视图接口参考：https://tiptap.dev/docs/editor/extensions/custom-extensions/node-views/react；当前项目固定 v2，实际兼容性按已安装源码、编译和业务验收确认，不直接照搬文档中的 v3 专属 API。
