# Tailwind UI 统一（2026-10-23）

沿用现有 Tailwind 与本地 ui.tsx 组件，不新增远程组件库、外部字体或运行依赖。主色统一为靛蓝，基础组件统一圆角、轻边框、阴影、间距、禁用态和键盘焦点。按钮/输入框/卡片的改进覆盖使用这些组件的文件、项目、成员等页面。

侧栏加强品牌和组织切换层次，父级导航在子页面保持选中并提供aria-current。桌面侧栏固定可滚动；窄屏抽屉支持遮罩、Escape关闭、选导航后收起。白板模式选择改用共享Button组件，选中态清晰区分Mermaid与自由画布。页面标题和操作区可换行；尊重系统减少动画偏好。

业务接口、权限、数据模型、协作协议不变。未全面替换历史页面的所有原生控件，不宣称第三方Office引擎内部UI或全站移动端已全面验收。
