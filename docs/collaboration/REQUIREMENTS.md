> 说明：CollabSpace 是个人作品集项目，场景、角色和数据均为合成设计，不代表已完成用户访谈、市场验证或真实客户交付。本文描述“要做什么、为什么、如何验收”，实现状态以功能归档和 evidence 为准。

## 1. 背景与问题

中小型项目团队通常把协作拆散在多个工具里：文档在网盘、表格在 Office、流程图在白板、沟通在 IM、审批在邮件。由此产生四个问题：

1. **权限边界不清**：项目成员能看到什么、客户能评论什么、撤销权限后旧会话还能不能写入，缺少统一答案。
2. **实时协作不可信**：多人同时改同一段内容时，冲突、离线、断线重连和“是否真的保存成功”经常混在一起。
3. **AI 只会生成，不会安全地改**：模型可以写一段文字，但很难在权限、版本、审计和幂等约束下修改真实业务内容。
4. **交付证据缺失**：演示能跑，但没有可复核的拒绝、恢复、撤权和失败记录。

CollabSpace 的目标不是再做一款“功能更多的办公套件”，而是把**组织权限、实时协作、内容生产、AI 受控写入和可追溯交付**放在同一条链路上。

## 2. 产品定位与目标用户

**一句话定位**：面向 5–50 人项目团队的多租户协作空间，让成员在同一项目里写文档、改 Office、画白板、发消息，并在权限与审计约束下使用 AI。

| 用户 | 典型任务 | 关键诉求 |
| --- | --- | --- |
| 组织所有者 / 管理员 | 建组织、邀成员、配角色、看审计 | 隔离、可撤销、可追溯 |
| 项目经理 | 建工作区/项目、分派任务、组织交付 | 一个项目内完成内容与沟通 |
| 团队成员 / 编辑者 | 写文档、改表格、画流程、评审版本 | 实时、离线不丢、冲突可恢复 |
| 客户 / 评论者 | 看交付物、提评论 | 只读边界清晰、评论可定位 |
| 访客 / 只读者 | 查看被授权的资料 | 不能越权写入 |
| 平台/运维人员 | 健康检查、发布、回滚、监控 | 状态可见、失败可恢复 |

## 3. 角色与权限

| 角色 | 组织层 | 项目/内容层 |
| --- | --- | --- |
| OWNER | 全部组织设置、成员、角色、审计、监控 | 全部项目内容；可授权/归档/删除 |
| ADMIN | 成员、角色、部门、邀请、审计（按菜单授权） | 被授权项目的管理能力 |
| EDITOR | 日常协作 | 编辑正文、评论、创建版本；不能改 ACL |
| COMMENTER | 日常协作 | 只读正文 + 评论 |
| VIEWER | 日常协作 | 只读 |
| 平台管理员 | 跨组织运维入口 | 不默认读取业务正文 |

规则：

- 所有业务查询必须带**服务端验证的 organization_id**；数据库 RLS 是防御层，不是唯一授权层。
- 文档/白板/Office 有独立 ACL；项目可见不等于文档可见。
- 最后一个有效 Owner 不能被移除或降级。
- 父级停用、项目归档、ACL 撤销优先于子级授权。
- 前端隐藏按钮不构成权限控制；HTTP、WebSocket、历史、评论、导出都必须统一校验。

## 4. 核心用户旅程

1. **开通与邀请**：注册 → 邮箱验证 → 建组织/工作区/项目 → 邀请成员 → 分配角色。
2. **共同写一份交付文档**：Owner 建文档 → Editor 编辑 → Commenter 评论 → 解决评论 → 创建命名版本。
3. **断网与恢复**：Editor 离线继续写 → 恢复网络 → 本地草稿与服务端更新收敛 → 状态明确显示“已保存到服务器”。
4. **Office 往返**：上传 DOCX/XLSX/PPTX → 在线编辑 → 保存到服务器 → 导出 PDF 或另存私有副本。
5. **白板/图表**：新建白板或 Mermaid → 拖图元/连线/改字 → 切换图元或源码 → 导出 SVG、PNG、PDF 或离线 HTML。
6. **AI 受控修改**：选中范围 → 描述目标 → 生成计划/预览 → 用户确认 → 单次事务提交 → 审计可追溯。
7. **语音输入**：录音 → 服务端识别 → 转写回填可编辑草稿 → 用户检查后发送。
8. **治理与审计**：管理员查看成员、角色、邀请、登录日志、操作审计；撤权后旧会话被冻结。

## 5. 范围

### 5.1 P0（已交付或已上线）

- 多组织、工作区、项目、成员、部门、岗位、角色、邀请。
- 邮箱注册/验证/登录/重置密码；登录限流；OAuth（按环境配置）。
- 富文本、Markdown、白板/Mermaid、Office 文件；评论、版本、自动快照。
- 白板基础图元工具、箭头拖线、连接点命中、目标高亮；支持图元间绑定连接线与空白处自由箭头。
- 白板多选、框选、组拖、六向对齐、水平/垂直分布、批量复制/删除。
- 白板智能对齐参考线、层级置顶/置底/上移/下移。
- Mermaid 源码/图元开关式视图；白板图元级评论与评审模式。
- 实时多人编辑、在线状态、离线续写、断线重连、durable ACK。
- 文档/白板/Office 权限、最后 Owner 保护、撤权冻结、审计。
- IM 单聊/群聊、已读、输入中、附件、语音听写。
- 全局搜索、通知中心、邮件（验证/邀请/项目邮件）。
- 协作助手与 AI 工作助理；AI 写操作“计划 → 确认 → 应用”。
- 白板 AI：新增矩形/椭圆/菱形/便签/文字/主题、改字、移动、连线、自动布局，单次最多 20 个操作。
- ElevenLabs ASR/TTS；私有素材草稿；预设/卡通数字人与基础口型预览。
- 管理后台、监控、套餐沙盒、生产部署与健康检查。
- 白板导出 PNG(2x)/PDF：文字、便签、箭头、中文保留；支持选中区域与全部；PDF 可打印。
- 持久分组、锁定、旋转：写入 `boardMeta`，刷新与第二会话保留；锁定图元可评论不可拖动。
- Frame 与图层：Frame 裁切内容且可整体移动；图层显隐/锁定/排序持久化。
- 流程图自动布局：按连接线分层、节点不重叠、正交/曲线走线，一次撤销回退。
- 形状库扩展与搜索：覆盖 UML、ERD、网络、云厂商、K8s、BPMN 核心图形。
- 评论 @提及与通知：通知中心未读、点击定位到文档/图元、无权限成员不可被 @。
- 公开只读分享：创建时快照、可设到期与撤销、独立 RLS 读取、不泄露组织其他内容。
- `.drawio` 导入导出：图形/文字/连接线迁移与“逃生通道”。

### 5.2 P1（下一步候选）

- 项目数据联动图元、Frame 演示播放。
- Mermaid 双向同步（替换/合并式回写，而非只追加）。
- 多实例 WebSocket、跨地域、正式压测与备份还原演练。
- 真实支付、会议/音视频重新上线、真人数字人视频供应商接入。
- 更细的 AI 评测集、成本预算与失败回放。

### 5.3 非目标

- 不做完整 ERP/CRM/财务系统。
- 不做匿名公开协作编辑；公开分享仅限创建时的只读快照（可到期/撤销），不提供跨组织实时协作。
- 不宣称完整 Office 格式兼容、任意 Mermaid 语法回写或企业 SSO。
- 不用“演示数据 + 沙盒支付”冒充真实商业运营。

## 7. 非功能需求

| 编号 | 要求 | 当前口径 |
| --- | --- | --- |
| NFR-01 | 安全 | 服务端组织上下文 + PostgreSQL RLS + 资源 ACL + 撤权竞态检查 |
| NFR-02 | 可靠性 | durable ACK；进程重启后可从数据库重建；失败不伪装成功 |
| NFR-03 | 性能 | 单文档 5MiB、WS 单帧 256KiB、白板 500 图元；p95 目标见下，未做正式压测 |
| NFR-04 | 可用性 | 健康检查 `/health/ready`；单实例 WS；无 SLA 承诺 |
| NFR-05 | 可访问性 | 键盘导航、焦点管理、aria 标签、语义标题；持续改进 |
| NFR-06 | 可观测性 | trace_id、结构化日志、审计、监控页；不记录正文和二进制 |
| NFR-07 | 隐私 | 私有素材仅本人可见；供应商外发需明确配置；密钥不进仓库/浏览器 |
| NFR-08 | 可维护性 | 文档、功能归档、evidence、发布/回滚记录可追溯 |

性能目标（未宣称已达成）：远端可见 p95 <300ms、durable ACK p95 <500ms；2026-10-20 曾接受约 0.43s 多房间延迟作为当时基线。任何新报告必须附硬件、RTT、数据规模、样本数和 p50/p95/p99。

## 9. 指标

- **交付指标**：功能归档覆盖率、evidence 可打开率、验收状态可追溯率。
- **协作指标**：实时同步延迟、durable ACK 延迟、重连成功率、撤权拒绝率。
- **AI 指标**：计划确认率、重复提交拦截率、撤权后拒绝率、人工返工次数。
- **语音指标**：识别成功率、合成成功率、失败不重试率、单次时长/字数超限拒绝率。
- **运营指标**：健康检查成功率、发布回滚耗时、审计查询命中率。

当前没有真实用户，因此不提供 DAU、留存、转化等商业指标；面试演示使用合成账号与合成数据。

## 10. 假设、风险与边界

- 假设团队规模 5–50 人、单区域部署、以桌面浏览器为主。
- 风险：单实例协作服务、Office 引擎依赖、外部 AI/语音供应商额度与合规、备份还原未演练。
- 已知边界：支付沙盒、会议关闭、真人数字人未接入、跨实例同步未验证、单文档 5MiB/白板 500 图元。
- 真实外发、资金和生产发布按用户授权执行；不把模型流返回、HTTP 200 或广播 hash 当作业务完成。
