# 原生 Markdown 与 Office 文件协作（新增必需范围）

用户追加：实时共同修改 .md；常用办公文件在线打开并编辑，右上角显示真实编辑者，具备并发冲突管理；以 Microsoft Office 文件往返验收。此范围是核心文件协作能力，不归入远期 AI/高可用任务。

## 当前核实状态：未实现

- 富文本 Tiptap 的 Markdown 输入快捷方式不是 .md 源码编辑，也没有原生 .md 导入/导出/文件版本闭环。
- /files 当前只有列表、下载、分享，上传在项目页；没有 .docx/.xlsx/.pptx 在线协同编辑引擎、会话回调与文件保存闭环。
- 现有协作文档的在线成员、Yjs冲突合并、离线、评论与历史只证明其自己的对象模型，不能算上传文件的验收。

以下是新交付契约，全部为待实现/待验收，不是已完成功能。

## MF：Markdown 文件

1. 项目/文件中可新建与上传UTF-8 .md，保存名称与文件身份；原始 Markdown 文本为唯一内容源，不能先转富文本再导出并丢失原语法。
2. 源码/预览/分屏；支持常用GFM标题、列表、任务、表格、引用、代码围栏、链接与Mermaid围栏。预览禁任意HTML脚本与不安全URL，外部资源访问需要明确策略，不隐式把私有文件公开。
3. 原生源码绑定独立Y.Text，复用组织/项目/文档授权、持久化ACK、pending、离线重连和版本；新增类型/根需先做兼容迁移与协议协商，不能把.md偷偷存进已有白板的mermaid根。
4. 两人同时输入、修改同一行、删除与插入交错，最终源码一致，不丢已确认编辑；CRDT文本一致不承诺自动修复语义或Markdown语法冲突。
5. 在线头像/名字/编辑状态与源码光标，身份来自服务端；离线者不能显示为仍在线。
6. 可下载真正的.md并再次导入，换行/BOM/Unicode处理明确；历史预览和恢复私有副本保留完整源码，不污染原文件。

## OF：Office 文件

对象首版明确为Word .docx、Excel .xlsx、PowerPoint .pptx。旧.doc/.xls/.ppt、宏/VBA、复杂外部数据源、加密文件不自动宣称支持；导入时必须识别并清晰提示。

### 共同平台契约

- 文件列表点击后进入实际编辑器，不以下载、PDF预览、文本提取或伪表格替代。
- 右上角显示真实同文件参与者、编辑/只读/断线状态；文件ID、用户ID、租户与权限均由服务端确定。
- Word段落/图片/表格，Excel单元格/公式/工作表，PowerPoint文本/图片/幻灯片，分别需要多人编辑样本。
- 编辑引擎拥有其内部细粒度协作状态；CollabSpace拥有文件版本、权限、会话租约和持久保存。不能将OOXML二进制当Y.Text广播，也不能让Yjs和Office引擎同时全量写同一个文件。
- 同一活动文件版本的参与者必须加入同一协作会话/key；不能给每人生成不同key导致实际各编一份。
- 签名的短期文件读取能力和保存回调绑定租户/文件/版本/会话；签名检查、重放幂等、允许的下载源、大小限制、SSRF与回调乱序均需验证。
- 保存以文件head revision和会话generation进行栅栏校验；手动重传、旧会话保存、网络重试与新版本冲突不能静默覆盖。保存失败明确显示未持久化，保留可恢复版本。
- 撤权后要阻止该用户继续进入/编辑；需要验证编辑引擎的连接撤销能力及已排队操作边界，不能仅隐藏前端按钮。
- 历史版本、恢复副本、审计、评论能力应与实际格式对应。Office断线能力由引擎验证，不能沿用Yjs文字离线结论。

### Microsoft Office 验收

每种格式准备固定样本：上传 → 两人在线协同修改 → 可见参与者 → 并发/断线/保存冲突 → 重开内容 → 下载 → 使用Microsoft Word/Excel/PowerPoint打开。

核对内容、图片、表格/公式、工作表/幻灯片结构及选定样本的排版；记录不兼容项。不能用“文件未损坏”、HTTP200或编辑器截图代替格式正确与协作完成，也不宣称与Office所有高级特性完全兼容。

### 引擎路线：已选择兼容 Office 文件

用户已选择兼容 Office 文件路线，并授权先隔离开发验证 ONLYOFFICE 社区版。当前新机上的独立测试服务仅使用合成账号/文件，通过私有隧道访问，不接入生产登录或生产文件。社区版源码交付准备后置，不阻塞隔离开发；不将开发桥接器当生产租户授权系统。

- **兼容Office格式的嵌入式编辑器**：可评估ONLYOFFICE Docs，其服务负责多人编辑，应用负责受控文件访问/保存回调；部署前核对适用许可证、资源要求和并发限制。它不是微软原版Office，也不自动证明Office往返兼容。
- **微软原版Microsoft 365 for the web**：需按官方CSPP/WOPI合作接入流程申请、测试和验证；不是拥有个人Microsoft365账号即可直接嵌入。实际合作资格与授权是外部前置条件。

现有服务器磁盘约3.6GB可用（上一轮发布后快照），不据此直接加装重量级Office编辑服务。用户已有新机可评估，但应现场核对资源、许可证、持久存储和独立部署，不影响已有项目。
