# 画布之上 · 绘图工具选型指南 — PRD

> 版本：v1.0 · 2026-11-21
> 产品代号：Above the Canvas / 画布之上
> 交付形态：零依赖静态站点（HTML + CSS + ES Modules），部署到 Vercel

## 1. 背景与问题

绘图工具的功能正在高度同质化：拖拽、连线、样式、导出，几乎所有产品都能做。真正拉开价格差距的是“画布之上”的那一层——协作、权限、数据联动、AI 与生态集成。

目标用户面对 draw.io、Mermaid、Excalidraw、Lucidchart、Miro、Visio、Whimsical 等产品时，常见问题是：

- 只看到功能清单，不知道哪些能力是免费档就有、哪些必须付费；
- 不知道自己的团队规模、合规要求和预算应该对应哪一档产品；
- 选型文章很长，但缺少可交互的对照与决策路径。

## 2. 产品目标

用一页可交互的技术选型指南，回答三个问题：

1. 七层能力分别是什么？哪些是地板功能，哪些是溢价点？
2. 不同工具在七层上的覆盖差异是什么？
3. 按我的场景、团队规模、合规与预算，应该选哪一个？

### 成功标准

- 用户能在 3 分钟内完成一次选型并获得明确推荐；
- 对比矩阵在桌面与移动端都可读、可筛选；
- 首屏 LCP < 2s（静态资源、无图片依赖、无第三方运行时）；
- 选型结果包含“推荐 + 备选 + 注意事项”，不是单一结论。

## 3. 用户与场景

| 用户 | 典型场景 | 关注点 |
| --- | --- | --- |
| 技术团队负责人 | 架构图、时序图、流程图、技术文档 | 图形库、Mermaid/代码、SVG 导出、Git 版本管理 |
| 工具选型决策者 | 10 人以上团队的正式采购 | 协作、SSO/审计、权限、集成、预算 |
| 个人用户 | 快速草图、脑暴、个人项目 | 免费、上手快、无账号负担 |

## 4. 范围

### 4.1 核心模块

#### M1 · 七层能力阶梯

- 展示 7 层能力：基础绘图、图形库与模板、协作、数据联动与图即代码、权限与企业治理、导出与集成、AI。
- 每层包含：编号、名称、一句话定义、关键能力清单、免费/付费分水岭说明、工具覆盖概览。
- 交互：点击层级可跳转并高亮矩阵对应行；支持展开/收起；桌面端为阶梯式索引，移动端为纵向列表。

#### M2 · 七层能力对比矩阵

- 行：7 层能力；列：7 个代表工具。
- 单元格：0–3 级覆盖（无 / 有限 / 可用 / 完整），以条形或点阵可视化。
- 支持：按工具筛选、按用户类型/预算场景筛选、点击单元格查看说明。
- 响应式：移动端表格在容器内横向滚动，首列和表头保持可读，不造成页面横向溢出。

#### M3 · 选型决策助手

- 分步问答：主要场景、团队规模、实时协作、合规治理、代码/数据联动、预算。
- 根据答案计算候选分数，输出：首选、备选、推荐理由、注意事项、建议档位。
- 支持返回上一步、重新开始；结果可复制（可选）。
- 逻辑必须可解释：每条推荐理由对应一个用户答案。

#### M4 · 工具卡片与“钱花在哪”可视化

- 7 张工具卡：定位、价格档、最适合、七层强度、主要优势与限制。
- “钱花在哪”带状图：区分免费档可得能力与付费档解锁能力。
- 价格仅为量级参考，页面明确标注“以各产品最新定价为准”。

### 4.2 非目标

- 不做真实绘图画布；
- 不做账号、登录、支付、协作或评论；
- 不接入第三方工具 API 或实时数据；
- 不做工具排名背书或采购代理。

## 5. 功能需求与验收

| 编号 | 需求 | 验收标准 |
| --- | --- | --- |
| FR-01 | 七层内容完整呈现 | 7 层全部渲染，文本与源分析一致，无缺层 |
| FR-02 | 阶梯与矩阵联动 | 点击任一层，矩阵对应行高亮并滚动到可视区域 |
| FR-03 | 矩阵筛选 | 工具筛选、场景筛选即时生效；清空后恢复全量 |
| FR-04 | 单元格说明 | 点击任意单元格显示工具、层级、覆盖等级与说明 |
| FR-05 | 选型向导 | 6 步问答可前进/后退；完成后 100% 给出推荐与备选 |
| FR-06 | 规则可解释 | 结果中的理由来自用户选项，不出现无依据结论 |
| FR-07 | 工具卡 | 7 张卡均包含价格、最适合、优势、限制与七层迷你条 |
| FR-08 | 暗色/亮色 | 默认跟随系统；手动切换后持久化；两种主题对比度达标 |
| FR-09 | 响应式 | 390 / 768 / 1440 三档无页面级横向溢出；导航可用 |
| FR-10 | 性能 | 本地/线上 LCP < 2s；首屏请求数 ≤ 6；总传输 < 300KB |
| FR-11 | 无障碍 | 键盘可完成向导与筛选；焦点可见；图标按钮有 aria-label；`prefers-reduced-motion` 生效 |
| FR-12 | 监控 | 提供 `/health.json`；Vercel 部署日志与 Analytics 可开启；页面无控制台错误 |

## 6. 非功能需求

- **响应式**：移动优先；断点 640 / 900 / 1200；矩阵横向滚动限制在组件内。
- **暗色模式**：CSS 变量双主题；默认 `prefers-color-scheme`；切换持久化到 `localStorage`。
- **性能**：无框架运行时、无 Web 字体请求、无图片；CSS/JS 压缩后 < 100KB；使用 `content-visibility` 与 IntersectionObserver。
- **可访问性**：语义化标题层级、`fieldset/legend`、`aria-expanded`、`aria-live`、可见焦点、对比度 ≥ 4.5:1。
- **SEO**：标题、描述、Open Graph、`robots.txt`、`sitemap.xml`、结构化数据（WebSite）。
- **兼容性**：Chrome/Edge/Safari/Firefox 最近两个大版本；不支持 IE。

## 7. 数据与内容规则

- 工具覆盖等级为编辑判断，依据用户提供的分层分析；页面标注“编辑评分，非厂商官方认证”。
- 价格使用“免费 / 约 $8–20 / 企业采购”量级，不写死具体账单。
- 任何“最值得”结论都必须带适用前提，避免绝对化。

## 8. 指标

- 选型向导完成率；
- 矩阵单元格点击率；
- 工具卡到官网的出站点击；
- 首屏 LCP、CLS、INP（Vercel Analytics / Speed Insights）。

## 9. 发布与运维

- 静态站点部署至 Vercel，全球 CDN；
- 自定义域名优先 `diagram.purelamp.uk`，需在 Cloudflare 添加 CNAME；
- `/health.json` 作为可用性探针；
- 上线后检查：首页 200、资源 200、无控制台错误、移动端无溢出。
