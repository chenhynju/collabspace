# 画布之上 — UI/UX 设计规范

## 1. 概念

**Blueprint / Night Studio（蓝图夜工坊）**

这是一个“技术选型现场”，不是 SaaS 营销页。视觉上借用制图台、描图纸、测量标注和工程索引：

- 背景是低对比度蓝图网格；
- 内容以“图层 / 编号 / 标注”组织；
- 强调色像制图笔：荧光青柠、冷青、警示橙；
- 标题使用编辑感衬线，数据与标签使用等宽字；
- 动效克制：进入时逐层升起，悬停时像游标扫过。

记忆点：右侧的 **七层阶梯**——每一层对应一张能力卡，点击后整页矩阵像被游标定位。

## 3. 字体

- 展示 / 标题：`"Iowan Old Style", "Palatino Linotype", "Songti SC", "STSong", "SimSun", Georgia, serif`
- 正文：`"Avenir Next", "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", system-ui, sans-serif`
- 数据 / 标签：`"IBM Plex Mono", "SFMono-Regular", ui-monospace, Menlo, Consolas, monospace`
- 不加载 Web 字体，避免额外请求和 FOUT；用字号、字距、大小写建立层级。

## 4. 布局

- 最大内容宽度 1240px；两侧 24/40px 留白。
- 12 列网格，但允许标题与图表跨列、非对称。
- 顶栏：左侧字标，中央锚点导航，右侧主题切换与“开始选型”。
- 首屏：左 7 列文案，右 5 列阶梯图；移动端上下堆叠。
- 章节头：编号 + 英文小标 + 中文衬线标题 + 一句说明 + 细线。
- 矩阵：首列 sticky，表头 sticky；容器内滚动。
- 工具卡：2/3 列网格，卡片顶部细线 + 编号。

## 5. 组件

### 七层阶梯

- 7 行，每行有：`01`、中文层名、英文短标、覆盖强度条、箭头。
- 行高从下到上递增 2px，形成“阶梯”感。
- 悬停 / 聚焦：背景变为 acid 低透明，右侧箭头移动。
- 点击：滚动到矩阵，高亮对应行，显示说明。

### 覆盖矩阵

- 单元格三格条：3 实心、2 两格、1 一格、0 空心。
- 颜色：完整 acid、可用 cyan、有限 orange、无 muted。
- 行/列十字高亮；单元格可聚焦，`aria-label` 读出“工具 + 层级 + 等级”。
- 点击后在矩阵下方显示说明条，不弹模态。

### 选型向导

- 进度条 + `01 / 06`。
- 选项为可聚焦的卡片，`input type=radio` 视觉隐藏但可键盘操作。
- 单选后自动进入下一步（可关闭自动前进？保持手动“下一步”，避免误触）。
- 结果：大号首选名 + 分数条 + 三条理由 + 注意事项 + 备选。

### 工具卡

- 顶部：编号、名称、定位标签、价格。
- 七层迷你条。
- “最适合”一句话。
- 优势 / 限制两列。
- 外链按钮。

## 6. 动效

- 首屏：标题、说明、按钮、阶梯依次 60ms 延迟进入。
- 滚动：IntersectionObserver 添加 `is-visible`，位移 12px + 透明度。
- 手风琴：`grid-template-rows: 0fr → 1fr`，220ms。
- 主题切换：CSS 变量过渡 200ms。
- `prefers-reduced-motion: reduce` 时全部关闭。

## 7. 响应式

- `< 640px`：导航收进菜单；首屏单列；矩阵横向滚动；工具卡单列；向导选项单列。
- `640–899px`：工具卡两列；矩阵仍横向滚动。
- `≥ 900px`：首屏双列；阶梯完整；矩阵完整；工具卡三列。

## 8. 可访问性

- 所有交互为原生 `button` / `input` / `a`；
- 焦点环 2px acid，offset 3px；
- 图标按钮有 `aria-label`；
- 主题切换 `aria-pressed`；
- 向导步骤使用 `aria-live="polite"` 报告进度；
- 矩阵说明条 `role="status"`；
- 对比度在两种主题下均 ≥ 4.5:1。

## 9. 性能预算

- HTML < 30KB，CSS < 35KB，JS < 25KB（未压缩）；
- 0 图片、0 Web 字体、0 第三方脚本；
- 首屏只依赖一个 CSS 和一个 JS；
- 使用 `content-visibility: auto` 延迟离屏章节；
- 目标 LCP < 2s（本地与 Vercel 边缘）。

## 10. 文案语气

- 结论先行，短句；
- 不写“最强”“第一”，写“适合 / 不适合 / 前提”；
- 数据与价格标注来源与时效；
- 中文为主，英文用于索引标签与产品名。
